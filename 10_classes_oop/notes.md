# javascript and classes

- Javascript is primarily a prototype-based language.
- Javascript does have classes. However, it classes are primarily syntactic sugar over existing prototype-based inheritannce mechanisms.

# OOP 
- Object Oriented Programming
- Used to organize code using objects

# Object
- Collection of properties and methods

# why use OOP
- code reusability
- better structure
- easy maintenance
- real-world modeling

# parts of OOP
- Object Literal
- Constructor function
- Prototypes
- Classes
- Instances (new, this)

# 4 pillars
- Abstraction : hides unnecessary details, shows only important features
- Encapsulation : binds data and methods together, restrict direct access to data
- Inheritance : one class acquires properties/methods of another class
- Polymorphism : same method behave differently in different situations
